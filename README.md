# מפת השפע

אתר שבו כל אחד יכול לשתף מיקום של אוכל או חפצים שמחכים בחינם ברחוב, למשל ארגז ירקות סוג ב׳ ליד
המכולת או ספה ליד הפח. כולם רואים את המציאות על מפה וברשימה, ויכולים לעדכן: **עדיין שם** /
**נלקח** / **לא מצאתי** / **לא במצב טוב**. לא צריך להירשם.

האתר נבנה כ**רקמה** בפלטפורמת [1💗1](https://www.1lev1.com/). אפשר להכיר את
[דף הרקמה](https://www.1lev1.com/project/89) ולהצטרף כמפתחים או כבודקי תוכן, או
[לתמוך בעשייה](https://www.1lev1.com/project/89/support).

## הרצה מקומית

```sh
npm install
npm run dev
```

זהו. בפיתוח משתמשים ב-[PGlite](https://pglite.dev), מסד Postgres שרץ בתוך Node ושומר את הנתונים
בתיקייה `.data/`. הטבלאות נוצרות אוטומטית בהפעלה הראשונה, אז לא צריך להתקין שום דבר נוסף.

## פרודקשן (Neon)

1. יוצרים מסד ב-[Neon](https://neon.tech) ומגדירים `DATABASE_URL="postgres://..."`.
2. `npm run db:migrate` מריץ את קובצי ה-SQL שבתיקייה `drizzle/`.
3. מחליפים את `adapter-auto` באדפטר של פלטפורמת האירוח (Vercel / Netlify / Node).

## מבנה

| נתיב                                | מה יש שם                                             |
| ----------------------------------- | ---------------------------------------------------- |
| `src/routes/+page.svelte`           | מפה + רשימה, כולל מיון לפי "מה קרוב אליי"            |
| `src/routes/new/`                   | טופס פרסום מציאה (סוג, מיקום מה-GPS או מהמפה, תיאור) |
| `src/routes/listing/[id]/`          | פרטי מציאה, ניווט ב-Waze/Google Maps, כפתורי עדכון   |
| `src/lib/server/listings.ts`        | חוקי המערכת: תפוגה, הגבלת קצב, מתי מציאה יורדת מהמפה |
| `src/lib/server/db/schema.ts`       | טבלאות `listing` ו-`report`                          |
| `src/lib/domain.ts`                 | קטגוריות, סוגי עדכון, זמני תפוגה                     |
| `src/lib/components/MapView.svelte` | מפת Leaflet (נטענת רק כשצריך)                        |
| `messages/*.json`                   | טקסטים בעברית, ערבית, רוסית, אנגלית וצרפתית          |

## חוקי המערכת (גרסה ראשונה)

- **תפוגה**: אוכל יורד מהמפה אחרי 24 שעות, חפצים אחרי 72 שעות. כל "עדיין שם" מאריך את הזמן.
- **"נלקח"** מוריד את המציאה מיד.
- **"לא מצאתי" / "לא במצב טוב"** משני אנשים שונים (מאז האישור האחרון) מורידים את המציאה.
- **בלי הרשמה**: כל דפדפן מקבל מזהה אקראי בעוגייה. הוא משמש רק כדי להגביל ל-10 פרסומים בשעה
  ולמנוע עדכון כפול מאותו אדם. לא שומרים כתובות IP או מיקום של המדווחים.

## עקרונות

1. **קליל**: בלי פונטים חיצוניים ובלי ספריות UI. המפה נטענת רק כשמציגים אותה.
2. **נגיש**: כפתורים גדולים, ניגודיות גבוהה, תמיכה בקוראי מסך וב-RTL, ורשימה כחלופה למפה.
3. **שפה פשוטה** בכל הטקסטים.

הפירוט המלא נמצא ב-[CLAUDE.md](CLAUDE.md).
